# Chapter problem banks

The four JSON files are separate databases by subject and set type:

- `calculus-c-bank.json`: AP Calculus BC C1–C12, 745 problems. C1–C11 are multiple choice; C12 contains 39 free-response problems.
- `calculus-t-bank.json`: AP Calculus BC T1–T10, 595 multiple-choice problems.
- `chemistry-t-bank.json`: existing AP Chemistry T1–T10 bank, unchanged by the Calculus review.
- `chemistry-c-bank.json`: empty placeholder, intentionally deferred.
- `calculus-ap-frq-bank.json`: 162 AP Calculus BC free-response questions, 1998-2025 (no 2020), from the APFRQs archive
  (`zenith-resources/apfrqs-archive`). Generated by `scripts/build_ap_frq_bank.py`; do not hand-edit. One set keyed `ap`
  (FRQ shape: `stem_tex`, no choices/answer). Each problem keeps its archive id (`25FRQ1` = 2025, printed question 1) plus
  tags: `year`, `number`, `calculator` (`yes`/`no`; the index leaves 21 blank, so it is inferred from the question number),
  and `units` (AP units 1-10 from apfrqs.com By topic, a problem can carry several; not independently checked). 66 have a
  `figure` (cropped from the source PDF into `data/calculus-figures/apfrq-<id>.png`; a few stack two images). There is no worked
  solution in the archive: `scoring_url` is the year's official scoring guidelines and `samples_url` the question's sample
  responses (both external links to the apfrqs mirror). Not yet loaded by `js/zp-banks.js`.

## Calculus review and LaTeX

`calculus-reviewed/` holds the authoritative source-reviewed chapter records. The review restores formulas, all four multiple-choice options, shared tables/graphs, and worked explanations using the source PDFs and LaTeX files under `/Users/kyj/Documents/zenith-resources/AP Calculus BC/`.

`calculus-review-status.json` reports exact coverage and any pending IDs. Do not infer completeness from the presence of an ID: the original extracted banks already contained IDs with missing content. `review_status: "source-reviewed"` identifies reviewed records.

Each bank is keyed by chapter number (as a string). A chapter contains `title`, `problems`, and, for multiple-choice sets, `answer_key`. C12 has `type: "frq"`; C1–C11 have `type: "mcq"`. T chapters are multiple choice.

A reviewed multiple-choice record has this shape:

```json
{
  "id": "A1",
  "stem_tex": "Evaluate $f(-2)$ for $f(x)=x^3-2x-1$.",
  "choices_tex": ["$-13$", "$-5$", "$-1$", "$7$"],
  "correct": "B",
  "explanation_tex": "Substitute: $f(-2)=-8+4-1=-5$.",
  "review_status": "source-reviewed"
}
```

C IDs retain the source's `A1`, `B1`, etc.; T IDs retain `T1`, `TB1`, etc. IDs are unique within a chapter and bank. Free responses use `stem_tex` and `explanation_tex`, with all subparts included, and do not require choices or an answer key.

Math uses KaTeX-compatible delimiters and commands. Tables use math `array` environments rather than document-only `tabular`; graphs are local images referenced by optional `figure: {"src": "data/calculus-figures/…png", "alt": "…"}`. Keep these assets with the JSON when copying the bank. Optional `source_correction` explains a source typo or an explicitly clarified assumption.

## Source defects and grading

The 27 source defects identified during review have now been repaired into single-answer questions. See `calculus-source-repairs.md` for the item-by-item changes. Each repaired record preserves its original content in `source_original`, the original defect in `resolved_source_issue`, and the change in `source_correction`. These repaired questions have valid `correct` values and synchronized chapter keys. Original PDFs remain unchanged.

If a future unresolved defect is recorded, use `source_issue` with `correct: null` and omit that ID from `answer_key`; such an item must remain ungraded. Do not confuse the historical `resolved_source_issue` field with an active defect.

For a valid multiple-choice item, compare the student's letter with `correct` or the synchronized chapter key. Use `explanation_tex` for feedback. Free responses are self-reviewed. The practice page excludes source-invalid questions from ordinary sets by default and can show them as ungraded study items.

## Regeneration and validation

Merge reviewed records into both banks and regenerate the coverage report:

```sh
python3 scripts/apply_calculus_reviewed.py
```

The legacy C extraction script also applies these reviewed records before writing output:

```sh
python3 scripts/parse_calculus_c_bank.py
```

The original C `.tex` files are lossy PDF text extractions; they are not a replacement for the curated records. If re-parsing T sources, run `apply_calculus_reviewed.py` afterward. Preserve `calculus-reviewed/` and its figure assets.

Validate IDs, coverage, choices, explanations, keys, source-defect handling, and figure references:

```sh
python3 scripts/validate_calculus_banks.py --require-complete
```

Compile all reviewed math spans using KaTeX 0.16.9 (the site's version):

```sh
node scripts/validate_calculus_math.cjs /path/to/katex.js
```

The validators check data structure and rendering syntax. Mathematical review also requires checking the source and the reasoning; passing these scripts alone does not prove an answer correct.
